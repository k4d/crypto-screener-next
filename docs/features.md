# 🚀 Features Roadmap

Этот файл содержит список планируемых и разрабатываемых функций для проекта **Crypto Screener Next**.

---

## 📊 Таблица задач

| Функция | Статус | Описание | Примечания |
| :--- | :---: | :--- | :--- |
| **Timeframes (Таймфреймы)** | 📅 В плане | Реализация переключения периодов графика (1ч, 4ч, 1д, 1н, 1м) с подгрузкой данных. | Требуется связать кнопки `TimeFrameButtons` с логикой загрузки данных. |

## 📝 Заметки по реализации

### Timeframes
- API CoinGecko (`/coins/{id}/market_chart`) принимает параметр `days`.
- Для таймфреймов меньше 1 дня (часы) нужно использовать меньшие значения `days` (например, `1` или `0.5`).

### Technical Indicators
- **Bollinger Bands**: Можно реализовать как 3 линии (Upper, Middle, Lower) с закрашиванием области между ними (через `AreaSeries` или `BaselineSeries`).
- **RSI**: Отображается в отдельном окне (0-100). В `lightweight-charts` это делается либо через второй экземпляр `createChart` синхронизированный по времени, либо через хитрое масштабирование (но второй экземпляр надежнее).

### Live Data
- Метод `series.update()` позволяет обновлять последнюю свечу в реальном времени без полной перерисовки графика.
- Для тестов можно использовать `setInterval`, в продакшене лучше WebSocket.

### Dark Mode
- При смене темы нужно вызывать `chart.applyOptions({ layout: { background: {...}, textColor: ... } })`.
- Важно сохранять позицию скролла (время) при смене темы.
