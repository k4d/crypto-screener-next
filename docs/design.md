# Руководство по UI-дизайну

Этот документ описывает основные принципы, стандарты и рекомендации для UI-дизайна
приложения Crypto Screener.

---

## 1. Основные Принципы

- **Ясность:** Интерфейсы должны быть интуитивно понятными и легкими для восприятия.
- **Последовательность:** Похожие элементы должны выглядеть и вести себя одинаково.
- **Эффективность:** Пользователи должны достигать своих целей с минимальными усилиями.
- **Адаптивность:** Дизайн должен корректно отображаться на разных устройствах.

---

## 2. Цветовая Палитра

Наша цветовая система построена на CSS-переменных и использует современный цветовой формат `oklch` для лучшей поддержки тем и доступности.

### Основные переменные

| Переменная     | Светлая тема (`:root`) | Тёмная тема (`html.dark`) | Описание                      |
| -------------- | ---------------------- | ------------------------- | ----------------------------- |
| `--background` | `oklch(1 0 0)`         | `oklch(0.05 0 0)`         | Основной цвет фона            |
| `--foreground` | `oklch(0.09 0 0)`      | `oklch(0.93 0 0)`         | Основной цвет текста и иконок |

Эти переменные используются в классах Tailwind, например `bg-background` и `text-foreground`.

---

## 3. Типографика

Система типографики использует три основных семейства шрифтов, определенных в `globals.css` и доступных через классы Tailwind.

- **Основной шрифт (`font-sans`):** **Manrope** - используется для основного текста, параграфов.
- **Шрифт заголовков (`font-heading`):** **DM Sans** - используется для всех заголовков (`h1`-`h6`).
- **Моноширинный шрифт (`font-mono`):** **DM Mono** - используется для отображения кода, цифр или данных, где важна ширина символов.

### Размеры текста (Пример)

- `h1`: `text-3xl font-bold`
- `h2`: `text-2xl font-semibold`
- `body`: `text-base`

---

## 4. Отступы и Макет (Spacing & Layout)

Система отступов основана на масштабе Tailwind CSS (по умолчанию `1 unit = 4px`).

- **Примеры утилитарных классов:** `p-4`, `m-8`, `space-x-4`.

---

## 5. Анимации и Переходы (Animations & Transitions)

Мы используем **View Transitions API** для плавных переходов между страницами.

- **Анимации:** `fade-in` (появление) и `fade-out` (исчезновение).
- **Длительность:** 500ms
- **Функция времени:** `ease-in-out`

Это создает более мягкий и приятный пользовательский опыт при навигации.

---

## 6. Рекомендации по Компонентам

### Кнопки

- **Основная кнопка:** `bg-primary-500 text-white font-medium rounded-md py-2 px-4`
- **Второстепенная кнопка:** `border border-gray-300 text-gray-700 rounded-md py-2 px-4`
